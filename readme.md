# Initialisation

- créer un readme
- initialiser un frontend - npm create vite@latest frontend - React - TypeScript - ESLint - Installer et démarrer : Y
  - nettoyer le repo créé
    - supprimer frontend/src/\*.css
    - supprimer les -appels au css dans frontend/src/\*.tsx
    - vider le fichier frontend/src/App.tsx
    - supprimer dossier frontend/src/assets
    - supprimer frontend/public/icons.svg
- initialiser un backend - cloner le template Express TypeScript du formateur dans le dossier backend - supprimer le dossier caché backend/.git - npm install - copier .env.sample en .env et définir API_PORT - supprimer la route /pokemon dans backend/src/index.ts - ajouter une route de test sur / - npm run dev pour vérifier que le serveur démarre
